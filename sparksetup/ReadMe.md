# To Run this code.

Open Terminal

Run:
```
docker compose down
docker compose up -d
```

- This will run the docker compose yaml and it will start up the spark cluster and the jupyternotebook.

- Any notebook created in the apps folder will show up in the jupyter notebook.
- Any notebook created in the jupyter workspace will appear in the apps folder.


```
The URL of the Jupyter can be taken from the dockerDesktop-> Containers -> pyspark -> Logs
```
